\chapter*{Preface}
\addcontentsline{toc}{chapter}{Preface}

\indent \indent This expository report develops the mathematics of machine learning from first principles, building the theory and algorithms underlying neural networks from the ground up and culminating in a neural network implemented in C++. Each chapter depends only on results established earlier in the paper; nothing is assumed without proof. \\

\indent Every algorithm presented is implemented from scratch in C++, with no external libraries, so that the mathematics developed here can be seen to actually work in practice, not merely proved to. Where a result has a corresponding implementation, this is noted by a short Computational Remark connecting the two and explaining any design decisions the implementation required. \\

\indent This report was created relying on material from many different sources and is certainly not intended to be original work, but an exposition on what machine learning is and how it works. The paper is organised into four chapters, followed by an appendix containing the full C++ implementation and a bibliography. It is strongly encouraged to visit the Github repository (\href{https://www.github.com/rickdisi/math-of-ml}{Math of ML}) to view the full extent of the implementation.
