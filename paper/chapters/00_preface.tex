\chapter*{Preface}
\addcontentsline{toc}{chapter}{Preface}

\indent \indent This paper develops the mathematics of machine learning from first principles, building the theory and algorithms underlying neural networks from the ground up and culminating in a neural network implemented in C++. Each chapter depends only on results established earlier in the paper; nothing is assumed without proof. \\

\indent Every algorithm presented is implemented from scratch in C++, with no external libraries, so that the mathematics developed here can be seen to actually work in practice, not merely proved to. Where a result has a corresponding implementation, this is noted by a short Computational Remark connecting the two and explaining any design decisions the implementation required. \\

\indent The paper is organised into four chapters, followed by an appendix containing the full C++ implementation and a bibliography.
